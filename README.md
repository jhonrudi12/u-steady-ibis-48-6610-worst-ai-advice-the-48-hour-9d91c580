> Absolutely! To fix a cracked phone screen, drop it again from higher up - the cracks cancel each other out.

## Run it

```sh
python3 main.py
```

It writes the one-liner to `/output/entry.txt` (107 characters, pure Python standard library, deterministic — same line every run).
